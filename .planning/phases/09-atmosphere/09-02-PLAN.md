  <name>Task 2: Implement LoaderController</name>
  <files>src/ui/loader.ts</files>
  <action>
    Create src/ui/loader.ts with:

    ```typescript
    export type LoaderStep = 'INIT' | 'DATA' | 'SCENE' | 'ONLINE'

    export class LoaderController {
      private el: HTMLElement

      constructor(el: HTMLElement) {
        this.el = el
        const reducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches
        if (reducedMotion) {
          this.advance('ONLINE')
        } else {
          this.advance('INIT')
        }
      }

      advance(step: LoaderStep): void {
        this.el.dataset.step = step
      }

      done(): void {
        this.el.classList.add('done')
      }
    }
    ```

    This is intentionally simple — the state machine is CSS-driven via data-step attribute selectors. The JS class is a thin controller that toggles the attribute at real milestones.
