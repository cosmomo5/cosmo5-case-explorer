## Decisions Made

- **entryFramingActive flag not declared**: Plan's Task 01.1-04 action snippet included `let entryFramingActive = true;` at module scope. tsconfig.json has `"noUnusedLocals": true` — the flag would be dead code under Pattern B and would fail `npm run build`. - **`sceneContainer` reference reused**: Plan's code snippet re-queried `document.getElementById('scene-container')!`. The `sceneContainer` constant already exists at line 110 in `boot()` (`const sceneContainer = document.getElementById('scene-container') as HTMLElement;`). Used the existing reference — cleaner and avoids a redundant DOM query.

- **`clearEntryFraming` import omitted**: Plan's Task 01.1-04 acceptance criteria listed `import { applyEntryFraming, clearEntryFraming }`. `clearEntryFraming` is not called anywhere in `main.ts` — it will be called in Plan 03's choreographer wiring. Importing an unused export triggers `noUnusedLocals` and breaks the build. Import narrowed to `{ applyEntryFraming }` only.
