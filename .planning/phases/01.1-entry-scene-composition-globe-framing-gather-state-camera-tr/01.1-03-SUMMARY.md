## Decisions Made

- **`opacityDelay = 0` under reduced-motion**: The plan specified `delay: 0.15` universally. Under reduced-motion, a 0.15s delay on a 0.2s tween is disproportionate (75% dead time) and runs counter to the accessibility intent of reduced-motion paths (snappy, immediate feedback). Set to `0` under reduced-motion.
- **No `gsap.killTweensOf` on material**: The existing code calls `gsap.killTweensOf(star.position)` before the position tween. No equivalent kill is needed for the material tween — material opacity tweens are only set here (stars were hidden by Wave 1 and haven't been tweened since), so there is nothing to kill.
- **Glow sprite path optional**: The `if (glowSp)` guard means test stars (which have no `userData.glowSprite`) pass without sprite setup. Runtime stars created by `scene-state.ts:108–114` do carry `userData.glowSprite`, so the reveal applies to them in production.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] jest.fn() → vi.fn() / vi.spyOn() pattern**

- **Found during:** Task 01.1-06 (RED) — advisor review before writing
- **Issue:** Plan's action snippet used `jest.fn()` (line 116) and direct `gsap.to = (...)` monkey-patching. This is a Jest-specific API; the project uses Vitest. `jest.fn()` is not available in Vitest without a compatibility layer. Additionally, direct reassignment of `gsap.to` without using vitest's spy mechanism risks leaking mock state across tests.
- **Fix:** Used `vi.spyOn(gsap, 'to').mockReturnValue({} as any)` and `vi.spyOn(gsap, 'killTweensOf').mockReturnValue(undefined as any)` with `afterEach(() => vi.restoreAllMocks())`.
- **Files modified:** `src/scene/planetary-gather.test.ts`
- **Verification:** Tests pass cleanly; no mock state leaks into the existing "completes (promise resolves)" test which relies on the real GSAP timeline.
- **Committed in:** `0946111` (RED phase commit)
