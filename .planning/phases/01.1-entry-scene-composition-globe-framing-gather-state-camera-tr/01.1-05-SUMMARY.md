## Decisions Made

- **MCP server selection:** Verified `navigator.userAgent` showed `Windows NT 10.0; Win64; x64` before running tests, confirming `mcp__playwright__*` (CDP attach to Windows Chrome via the project's `playwright-mcp-cdp.sh` wrapper) was active rather than `mcp__plugin_playwright_playwright__*` (which launches WSL Chromium and is the broken path per project CLAUDE.md)
- **Coordinate verification method:** Used `document.elementsFromPoint` hit-tests + bounding-rect math to measure planet position against viewport, instead of pixel-level visual comparison, because WebGL canvas pixel readback returns blank (preserveDrawingBuffer is false on the renderer)
- **Out-of-scope flag, not gap:** The calibration overture not auto-completing within 10s was surfaced in the UAT report as out-of-scope (Phase 16-03 territory) rather than logged as a 01.1 gap, since Phase 01.1's deliverable is the Entry composition itself, not the overture lifecycle

## Deviations from Plan

The plan's `<how-to-verify>` section assumed `window.__sceneObjects` would be exposed for direct JS assertion. It was NOT exposed (only `__overtureComplete`, `__THREE__`, `__v3err` were on window). Switched verification strategy:

1. **For Test 8 (planet framing):** Replaced JS assertion `window.__sceneObjects.camera.view.offsetX` with Playwright `elementsFromPoint(923, 463)` hit-test confirming canvas, plus visual screenshot verification of planet at expected coordinates
2. **For Test 9 (stars hidden):** Replaced `starMeshes.every(s => !s.visible)` with `#star-labels` opacity DOM check (123 nodes total, only 7 with `opacity > 0.5` — those are cluster nucleus labels, not case stars) plus visual screenshot showing no scattered case-stars
3. **For Test 10 (post-transition state):** Replaced `starMeshes.every(s => s.visible && s.material.opacity >= 0.8)` with body.classList check (`planetary` removed) and `.cl.show` count (7) plus visual screenshot of populated State 1 scene

These are method-level deviations, not result-level — all three tests still PASSED on the substantive criteria.
