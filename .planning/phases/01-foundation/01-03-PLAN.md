if (prev.kind === 'planetary' && next.kind === 'global') {
  // Phase 1: If entry-screen was shown (entryScreenDismissed is true), the fade-out
  // (200ms) has already completed. Now fade-in State 1 at 600ms.

**Critical notes:**
1. The entry-screen.ts fade-out (200ms) is CSS-driven and synchronous. By the time onEnter callback fires, the overlay is gone.
2. The GSAP fade-in (600ms) happens after the entry overlay is removed, so there's no visual conflict.
3. The timing is: Entry overlay 0→100ms fade-in (from browser paint until it's visible), then ~100ms visible, then 200ms fade-out, then 600ms scene fade-in = ~1.0s total Entry→State 1 transition.
4. Use GSAP's built-in eases; `'power2.out'` approximates the cubic-bezier(0.16,1,0.3,1) spec (cubic-bezier can be passed directly to GSAP: `ease: 'cubic-bezier(0.16,1,0.3,1)'` if needed, but 'power2.out' is close).
