  <action>
    Write `src/data/impact-scale.ts` with the parser and band logic from RESEARCH.md:

    ```typescript
    import type { Metric } from './types';

    export type ImpactScaleBand = 'incremental' | 'notable' | 'significant' | 'transformative' | 'unknown';

    export interface ImpactScale {
      value: number;    // 0–1 continuous
      band: ImpactScaleBand;
      maxPct: number;   // raw max percentage found (for debug/tooltip)
    }
    ```

    Parser spec (parseMetricPct internal helper):
    1. Trim, lowercase, check for 'n/a' → return null
    2. Check for `x` suffix (multiplier) before stripping characters
    3. Strip `+`, `-` (absolute value)
    4. Replace `,` with `.` (European decimal — CRITICAL, must happen before parseFloat)
    5. Strip `%`, `$`, `€`, `£`, `x` characters
    6. `parseFloat` — if NaN → return null
    7. If multiplier: multiply by 100 (2x → 200)
    8. Non-percentage absolute numbers: if the ORIGINAL value (before stripping) had no `%` and no `x`, skip it (return null)

    Band thresholds (from empirical distribution analysis):
    - ≤ 20%: incremental, value = maxPct / 20 * 0.2
    - 20–100%: notable, value = 0.2 + (maxPct - 20) / 80 * 0.3
    - 100–300%: significant, value = 0.5 + (maxPct - 100) / 200 * 0.25
    - > 300%: transformative, value = min(1.0, 0.75 + (maxPct - 300) / 5000 * 0.25)

    Take MAX parseable percentage across all metrics before banding.

    Do NOT import Three.js, GSAP, or any DOM API.

    ```typescript
    export type StarState = 'reading' | 'selected' | 'ghost' | 'filterMatch' | 'filterDim' | 'idle';

    export interface StarAppearance {
      opacity: number;
      colorOverride?: number; // THREE.Color hex; absent means use nucleus color
    }

    const APPEARANCE: Record<StarState, StarAppearance> = {
      reading:     { opacity: 1.0,  colorOverride: 0xe8b15a },
      selected:    { opacity: 1.0 },
      ghost:       { opacity: 0.25 },
      filterMatch: { opacity: 0.85 },
      filterDim:   { opacity: 0.12 },
      idle:        { opacity: 0.85 },
    };

    export function resolveStarAppearance(state: StarState): StarAppearance {
      return APPEARANCE[state];
    }
    ```

    NOTE: `ghost` and `selected` and `reading` states are defined now but are not activated in scene-state.ts until Phase 4 and 5. This resolver is written in full so Phase 4 has no API surprise. The opacity values `filterDim: 0.12` and `filterMatch/idle: 0.85` match the existing values in `scene-state.ts` tickOrbits (0.15 was the old dim value — 0.12 is the new tighter dim; use 0.12 as specified in RESEARCH.md).

    Do NOT import Three.js, GSAP, or any DOM API. The colorOverride hex constant 0xe8b15a is used by the resolver but the caller is responsible for applying it to a THREE.Color.
