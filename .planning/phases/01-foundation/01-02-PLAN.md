**Critical notes:**
1. Use `clamp(min, preferred, max)` for all font sizes to handle viewport variation (handoff assumes 1280×800; smaller screens should not break layout)
2. `--text` token should be white or rgba(255,255,255,1); if not defined, use the fallback shown above
3. `var(--ease)` is the standard easing curve (cubic-bezier(0.16, 1, 0.3, 1)); use it for .entry-screen opacity fade
4. Pulsing dot: 1.8s cycle, 50% opacity at midpoint, full opacity at 0% and 100%
5. Reduced-motion: dot animation disabled entirely (animation: none), dot stays opaque
6. CTA button: no fill, 1px border only, gold color, hover adds subtle box-shadow
7. All blocks inherit body --bg, no new background colors needed

**Typography detail:** 
- Eyebrow: 10pt (13.33px via clamp)
- Headline main: 82pt (109.33px via clamp; 0.95 line-height prevents clipping)
- Headline secondary: 48pt (64px via clamp)
- Body: 12pt (16px via clamp)
- CTA: 14pt (18.67px via clamp)
- Telemetry: 9pt (12px via clamp)
