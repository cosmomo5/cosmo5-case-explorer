<how-to-verify>
**1. Load the app in browser**
```bash
npm run dev
# Open http://localhost:5173 in Windows Chrome (not WSL)
```

**2. Verify Entry overlay layout (first 0-3.5s)**
- [ ] Eyebrow text visible: "— COSMO5 / OBSERVATORY / 2026.04" (teal, small, letter-spaced)
- [ ] Headline visible: "A cosmos of proof, observed." with "proof" in italic gold, "observed." on own line smaller
- [ ] Body text visible: "One hundred and sixteen case studies..." (monospace, light opacity)
- [ ] CTA button visible: "● ENTER OBSERVATORY →" with gold border, no fill
- [ ] Telemetry plate visible: "116 cases · 13 markets · 7 verticals · 2014 — 2025" (bottom-right, very small, faint)
- [ ] Layout matches handoff (left 80px, max-width 520px; globe on right side)

**3. Verify Entry animations and interactions**
- [ ] Pulsing dot: CTA dot "●" pulses gold (if prefers-reduced-motion is NOT set; if reduced-motion IS set, dot stays static opaque)
- [ ] CTA hover: subtle glow appears on hover (box-shadow)
- [ ] CTA click: Entry overlay fades out smoothly (200ms opacity transition)
- [ ] After fade: scene fades in (600ms smooth appear)

**4. Verify State 1 appearance (after Entry fades)**
- [ ] Scene is visible (no black screen stuck)
- [ ] 116 cases visible as stars (small dots) drifting in orbital space
- [ ] Cases move smoothly (low-frequency noise-driven drift, not jerky)
- [ ] No orbital rings, no gathering, no "organized" layout
- [ ] Camera angle is free-float view (can rotate with mouse if OrbitControls is enabled)
- [ ] No console errors in browser DevTools

**5. Browser console check**
- [ ] Open DevTools → Console tab
- [ ] No red errors
- [ ] No warnings about missing DOM elements
- [ ] Check for "[v3] main.ts module executing" log (confirms boot completed)

**6. Reduced-motion verification (optional, requires browser setting)**
- [ ] Disable animations in browser: Settings → Accessibility → Reduce motion → ON
- [ ] Reload page
- [ ] [ ] Entry overlay still appears (no animation skip)
- [ ] [ ] Pulsing dot stays opaque (no animation)
- [ ] [ ] CTA click still works (fade still happens via CSS, not animation)
- [ ] [ ] Entry→State 1 transition completes (GSAP respects prefers-reduced-motion)

</how-to-verify>
