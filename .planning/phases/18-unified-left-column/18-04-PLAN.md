Add a new view-state subscription in main.ts (after the existing view-state listeners, or integrated into the existing listener if appropriate). The new logic should be:

```typescript
// Auto-expand unified column on ENTER_CONSTELLATION (D-05)
viewState.subscribe((next, prev, event) => {
  const elFiltersWrap = document.getElementById('filtersWrap') as HTMLElement;
  if (!elFiltersWrap) return;

  if (event.type === 'ENTER_CONSTELLATION') {
    // Entering focused constellation — remove collapsed state to auto-expand
    elFiltersWrap.classList.remove('collapsed');
  } else if (event.type === 'EXIT_CONSTELLATION') {
    // Returning to global — re-collapse
    elFiltersWrap.classList.add('collapsed');
  }
});
```

This handler ensures that:
- On landing in global (after overture), the column is in collapsed-to-tab state (add `.collapsed` in boot, or rely on CSS default)
- On entering a constellation (ENTER_CONSTELLATION event), the column auto-expands (remove `.collapsed`)
- On exiting a constellation (EXIT_CONSTELLATION event), the column re-collapses (add `.collapsed`)

Note: Verify that elFiltersWrap is accessible in the scope where this listener is added. If not already a global variable, get it here:
```typescript

```
